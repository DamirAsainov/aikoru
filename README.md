# AIKORU — офлайн-ассистент пространственной ориентации (прототип v0.1)

Голосовой помощник для людей с нарушениями зрения. Он смотрит через USB-камеру,
предупреждает об опасностях и изменениях вокруг, узнаёт знакомых людей по лицу,
а по голосовой команде описывает обстановку или ищет предмет.
Поддерживает русский и казахский языки. После установки работает полностью офлайн.

## Как это работает

```
 микрофон ──► Vosk ru+kk ──► «Айкору» ──► Silero VAD (запись команды) ──► Vosk ru+kk ──► разбор команды
                                                                                            │
 камера ──► YOLOE + ByteTrack (~3 кадра/с) ──► события ──► YuNet+SFace (лица) ─────────┐   │
        └─► YOLOE (по запросу: «найди дверь») ◄── словарь / NLLB ru,kk→en ◄────────────┼───┤
        └─► Moondream2 («что вокруг?») ──► NLLB en→ru,kk ──────────────────────────────┤   │
                                                                                       ▼
                                                       Silero TTS v5 CIS (голос zhadyra, ru + kk) ──► наушники
```

| Компонент | Модель | Зачем |
|---|---|---|
| Детекция | YOLOE-11s-seg (ultralytics) | Поиск объектов по текстовому запросу (open-vocabulary) |
| Трекинг | ByteTrack (ultralytics) | Отличает новый объект от уже известного |
| Лица | OpenCV YuNet + SFace | Узнаёт знакомых, локальная база `data/faces.json` |
| VLM | Moondream2 (rev. 2025-06-21) | Описание сцены и ответы на вопросы о кадре |
| Перевод | NLLB-200 600M, CTranslate2 int8 | Moondream и YOLOE понимают только английский |
| STT | Vosk small ru + small kz | Слово активации и команды. Silero STT не поддерживает казахский |
| VAD | Silero VAD | Определяет конец команды по паузе |
| TTS | Silero v5_cis_base_nostress | Один голос для ru (`ru_zhadyra`) и kk (`kaz_zhadyra`) |
| Ударения | silero-stress | Расставляет ударения для русского TTS |

## Установка

Нужны Python 3.11–3.13 и Windows, Linux или macOS. Видеокарта не обязательна:
при `device: auto` используется CUDA, если она есть, иначе CPU.

```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate

# PyTorch: с NVIDIA GPU
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
# ...или без GPU (~110 МБ вместо ~3 ГБ)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

pip install -r requirements.txt
python scripts/download_models.py  # один раз, ~5 ГБ; после этого интернет не нужен
```

## Запуск

```bash
python -m aikoru                 # голосовой режим
python -m aikoru --show          # + окно с видео и рамками (Esc — выход)
python -m aikoru --text          # команды с клавиатуры (отладка без микрофона)
python scripts/selftest.py       # самопроверка всех компонентов
```

Загрузка моделей занимает 1–3 минуты. Когда всё готово, система говорит «Система готова».

## Голосовые команды

Сначала скажите слово активации **«Айкору»**, дождитесь короткого сигнала и произнесите команду.
Язык ответа совпадает с языком команды.

| Действие | Русский | Қазақша |
|---|---|---|
| Описать обстановку | «что вокруг», «что впереди», «опиши» | «айналада не бар», «сипатта» |
| Найти предмет | «найди дверь», «где светофор» | «есікті тап», «бағдаршам қайда» |
| Вопрос о кадре | «что написано на вывеске?» | любая фраза из 2+ слов |
| Кто рядом | «кто это», «кто рядом» | «бұл кім», «кім бар» |
| Запомнить человека | «запомни как Айгерим» | «Айгерім деп есте сақта» |
| Забыть человека | «забудь Айгерим», «забудь всех» | «Айгерімді ұмыт», «барлығын ұмыт» |
| Пауза фоновых подсказок | «стоп», «тише» | «тоқта» |
| Включить подсказки | «продолжай» | «жалғастыр» |

Если предмета нет в словаре (`aikoru/lexicon.py`), его название переводится на английский
через NLLB, поэтому искать можно что угодно, например «найди красный зонт».

**Запоминание человека.** Человек смотрит в камеру, вы говорите «Айкору, запомни как Айгерим».
Система берёт три кадра и сохраняет лицо под этим именем. Имя распознаёт Vosk, и редкие имена
маленькая модель может услышать неверно. Тогда повторите команду или поправьте имя в `data/faces.json`.

## Фоновый режим: только изменения

YOLOE с трекером ByteTrack обрабатывает примерно 3 кадра в секунду (`detector.scan_interval_s`).
У каждого объекта есть свой номер трека, поэтому система говорит только о **новом**:

| Событие | Пример фразы | Когда |
|---|---|---|
| Опасность | «Осторожно! Машина прямо, около трёх метров.» | Транспорт, столб или лестница прямо по курсу ближе 4 м. Повторяется, только если объект подошёл вплотную. Прерывает другие подсказки |
| Знакомый пришёл | «Справа: Айгерим, около двух метров.» | Лицо узнано в базе |
| Незнакомец | «Прямо: незнакомый человек, около двух метров.» | Лицо не узнано за 2 с, человек ближе 4 м. Несколько человек сразу объявляются одной фразой |
| Знакомый ушёл | «Айгерим больше не видно.» | Пропал и не вернулся за 4 с |
| Новый объект | «Слева: скамейка, около трёх метров.» | Новый трек ближе 4 м. Дальние объекты объявляются, когда подойдут ближе |

Пока ничего не меняется, система молчит. Если трекер дал тому же объекту новый номер
(после перекрытия или моргания детекции), новый трек наследует состояние старого:
того же класса, рядом и похожего размера. Повторного объявления не будет.

**Приватность.** `data/faces.json` хранит биометрические эмбеддинги лиц. Файл остаётся
на устройстве и исключён из git. Запоминайте людей только с их согласия.

## Настройка

Все параметры находятся в `config.yaml`: камера, интервал сканирования, список объектов,
порог слова активации, голос и т.д.

## Ограничения прототипа

- **Расстояние** считается грубо, по одной камере: по известной высоте объекта и высоте рамки. Для объектов без известной высоты используется размер рамки. Точность ±30–50%.
- **Слово активации** ловится нечётким сравнением с распознанным текстом. Если срабатывает плохо, добавьте свои варианты в `voice.wake_words` или измените `wake_threshold`.
- **Лица** узнаются на расстоянии примерно до 3–4 м: лицо должно быть не меньше 40 px. В темноте и при повороте в профиль распознавание не срабатывает.
- **Скорость:** на RTX 3070 YOLOE с трекингом даёт ~27 кадров/с, Moondream описывает сцену за 1–2 с, перевод занимает 0,1–0,3 с. На CPU описание сцены займёт ~10–20 с.
- **Зависимости:** Moondream2 требует `transformers<5`, его удалённый код не совместим с 5.x.

## Структура

```
aikoru/
  __main__.py     точка входа, офлайн-окружение
  assistant.py    оркестратор: потоки скана, команд, голоса
  camera.py       фоновый захват кадров
  detector.py     YOLOE (+трекинг ByteTrack), направление и расстояние
  scene.py        состояние треков: что появилось, что ушло
  faces.py        распознавание лиц, база знакомых
  vlm.py          Moondream2
  translator.py   NLLB-200 (CTranslate2)
  voice.py        слово активации, VAD, Vosk
  commands.py     разбор команд ru/kk
  tts.py          Silero TTS с очередью приоритетов
  lexicon.py      словарь объектов, фразы, числительные
scripts/
  download_models.py   загрузка моделей в models/
  selftest.py          самопроверка
```
